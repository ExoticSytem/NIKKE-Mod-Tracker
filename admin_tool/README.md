# NIKKE Admin

Herramienta separada del Mod Manager para el dueño/administradores del proyecto.

Permite editar la clasificación global NPC / Extra, subir o reemplazar imágenes globales por `ID + Ver`, ver entradas detectadas automáticamente como nuevas y ejecutar manualmente la sincronización de catálogo/imágenes.

La herramienta usa un Fine-grained Personal Access Token limitado a este repositorio. Permisos recomendados: **Contents: Read and write** y **Actions: Read and write**. El token puede guardarse mediante Windows Credential Manager usando `keyring`.

Los jugadores normales no necesitan esta herramienta ni ningún token.
