# NIKKE Mod Tracker Android

Aplicación Android enfocada en llevar un inventario de mods de NIKKE por personaje/skin (ID + Ver).

El APK se compila automáticamente con GitHub Actions. El código fuente de la versión preparada está empaquetado en `source.zip.b64`; el workflow lo reconstruye y genera el APK.

## APK

Ve a **Actions → Build Android APK → Artifacts** para descargar `NIKKE-Mod-Tracker-Android`.
