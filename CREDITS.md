# Créditos / Credits

## Español

NIKKE Mod Tracker es un proyecto personal creado rápidamente porque se me hacía incómodo recordar qué mods de NIKKE tenía, detectar duplicados y revisar qué skin o acción modificaba cada uno.

La idea y parte de la inspiración de interfaz y flujo vienen de **[BD2ModManager de bruhnn](https://github.com/bruhnn/BD2ModManager)** para Brown Dust 2. Todo el crédito para ese proyecto por la inspiración. NIKKE Mod Tracker fue desarrollado con ayuda de IA. No sabía si ya existía algo parecido para NIKKE; si a otros jugadores les sirve, pueden usarlo, probarlo y compartir sugerencias.

## English

NIKKE Mod Tracker is a quick personal project I made because it was getting inconvenient to remember which NIKKE mods I had, spot duplicates, and check which skin or action each mod affected.

The idea and part of the UI/workflow inspiration came from **[bruhnn's BD2ModManager](https://github.com/bruhnn/BD2ModManager)** for Brown Dust 2. Full credit to that project for the inspiration. NIKKE Mod Tracker was developed with AI assistance. I did not know whether something similar already existed for NIKKE; if other players find it useful, feel free to use it, test it, and share suggestions.
